# Lumenwood · 流光之森

独立第三人称森林探索游戏，面向 Windows PC 浏览器。玩家在安静而充满生机的奇幻森林中探索、观察，并发现环境的回应。整体体验与未来规划见[项目大纲与总体方案](docs/PROJECT_OVERVIEW.md)。

## 当前状态

P0 基础灰盒与 P1 探索手感已完成。首批角色、针叶树、发光植物和木屋模型已生成并接入：针叶树已由用户确认视觉，其余三种待游戏内视觉验收。角色已有待机、行走和奔跑动画；林间营地样板已接入程序化地形、白天/暮光光照、萤火粒子、合成环境声音，以及发光植物被唤醒时的地面光波与空间音符，仍待视觉、听感与用户验收。2026-11-12 场景整体升级（向设计图靠拢）：世界扩大约 2.5 倍、地面起伏；营地是 18–30 m 高的红杉与冷杉密林，林下有代码草地、蕨类、苔石、倒木和发光蘑菇；湿地有芦苇、木桥、脚踏石和低雾，林间有光束。P4 已实现、待试玩：从营地到古树的完整流程。依次是营地萤火航线（唤醒植物 → 引路萤火 → 点亮 INT-002 灯笼柱 → 打开北侧走廊）、萤光湿地（涉水、湿地航线、光桥与隐藏空地）、古树高地（坡道、苔石灯座、古树分段点亮）和结局卡，结局后可继续探索。另有首次字幕与停滞提示、随进度生长的生成式音乐，以及本地存档（继续旅程 / 新的旅程）。具体状态与实测记录以[项目进度](PROGRESS.md)和[资产清单](docs/ASSET_MANIFEST.md)为准。

## 本地运行

需要 Node.js 22 和 pnpm：

```bash
pnpm install
pnpm dev
```

点击开始后点击画面捕获鼠标；WASD 移动、Shift 奔跑、鼠标环视、Esc 暂停或恢复。窗口失焦、切换标签页或鼠标锁意外释放时会自动暂停。“继续探索”尝试恢复鼠标捕获；浏览器拒绝时，按提示点击画面。

画质当前控制像素比与阴影；可切换白天和暮光。音量控制合成环境声与音乐（点击开始按钮后启动，暂停时静音）；设置与游戏进度都保存在本地浏览器；标题页的“新的旅程”会清除进度存档。

## 验证与部署

```bash
pnpm typecheck
pnpm lint
pnpm test
pnpm build
pnpm test:e2e
pnpm preview
```

`pnpm test:e2e` 会构建并用 Playwright 运行浏览器交互测试和性能基线，默认使用本机 Chrome，可通过 `PW_CHANNEL` 切换；结果保存在 `test-results/`。开发模式或 URL 添加 `?debug` 时启用 `window.__lumenwood` 测试钩子。Vite 使用相对资源路径，构建产物适合静态托管。上述命令是操作说明，实际验证结果请查[项目进度](PROGRESS.md)。
