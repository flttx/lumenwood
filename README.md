# Lumenwood · 流光之森

独立第三人称森林探索游戏，面向 Windows PC 浏览器。玩家在安静而充满生机的奇幻森林中探索、观察，并发现环境的回应。整体体验与未来规划见[项目大纲与总体方案](docs/PROJECT_OVERVIEW.md)。

## 本地运行

2026-11-15 白天视觉更新：浅金日光、鲜活叶绿与偏冷林下阴影，减弱灰黄褪色和雾幕；矩形谜题沟壑改为自然弧形岸坡，补苔石、蕨类、野花及藤桥枝叶。详见[美术方向](docs/ART_DIRECTION.md)和[白天样板](docs/DAYLIGHT_SAMPLE.md)。镜盘、支架与根系仍为标明的临时美术，未调用付费生成服务。

2026-11-14 新增[白天玩法样板“借光生长”](docs/DAYLIGHT_SAMPLE.md)：沿开局目标找到两座日光镜，靠近按 E/Q 转动，把光送到对岸植物，长出可行走且会存档的藤桥。过桥取种子后返回营地接原主线。镜盘、支架和藤桥明确为临时美术；没有调用付费生成服务。已有点灯进度可在营地固定白天体验。

需要 Node.js 22 和 pnpm：

```bash
pnpm install
pnpm dev
```

点击开始后点击画面捕获鼠标；WASD 移动、Shift 奔跑、鼠标环视、Esc 暂停或恢复。窗口失焦、切换标签页或鼠标锁意外释放时会自动暂停。“继续探索”尝试恢复鼠标捕获；浏览器拒绝时，按提示点击画面。

画质当前控制像素比、阴影、反射与后期；可选择随旅程或固定白天、暮光、夜晚。白天近镜按 E/Q 转镜，高地近灯座面向古树按住 E，支线按 T 切换本地/主线指引。音量控制合成环境声与音乐（点击开始按钮后启动，暂停时静音）；设置与游戏进度都保存在本地浏览器；标题页的“新的旅程”会清除进度存档。

## 验证与部署

```bash
pnpm typecheck
pnpm lint
pnpm test
pnpm build
pnpm test:e2e
pnpm preview
```

`pnpm test:e2e` 会构建并用 Playwright 运行浏览器交互测试和性能基线，默认使用本机 Chrome，可通过 `PW_CHANNEL` 切换；结果保存在 `test-results/`。开发模式或 URL 添加 `?debug` 时启用 `window.__lumenwood` 测试钩子。Vite 使用相对资源路径，构建产物适合静态托管。界面标题字体是 OFL 字体的子集（`src/assets/fonts/`），改动界面或字幕文字后需用 `scripts/fonts/subset.py` 重新生成，用法见脚本说明。上述命令是操作说明，实际验证结果请查[项目进度](PROGRESS.md)。
