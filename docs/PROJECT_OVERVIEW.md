# Lumenwood 项目大纲与总体方案

版本：综合方案 v1.1，2026-11-10。本文整合现有设计，用于讨论方向；计划内容不代表已经实现，也不自动批准扩大当前开发阶段。正式角色造型与美术风格仍以 [美术方向](ART_DIRECTION.md) 为准。

## 1. 项目定位

Lumenwood（流光之森）是一款面向 Windows PC 浏览器的独立第三人称奇幻森林探索游戏。玩家以好奇心驱动，在安静而有生命感的森林里行走、观察、发现环境反应。体验重心是空间、光影与声音带来的惊奇和宁静。导入方案提出以玩家行动引发森林对光、声音与接近的连续回应，并以 15–25 分钟核心体验为暂定目标；萤火航线的重要程度与具体规则仍需验证。

## 2. 体验大纲

1. **进入**：在温暖、可辨方向的林间营地附近熟悉行走、奔跑和环视。
2. **探索**：沿可通行林径观察地标与植物，自己决定何时停留、转向或返回。
3. **发现**：靠近或停留时，环境以克制的光、动作或声音回应；具体触发方式需要原型验证。
4. **延伸**：从营地逐步感知萤光湿地与古树高地，萤火航线可提供引导与发现；是否承担必经玩法、区域连接和具体规则尚未确定。

导入方案还提出古树高地的视听收束、结束后继续探索，以及本地存档优先；均为目标而非已实现功能。概念板中的收集、记忆碎片和故事不是已确认系统。玩家引导、交互反馈、持久进度与通关条件均待验证。

## 3. 世界与空间方案

| 区域 | 设计作用 | 视觉与体验方向 | 状态 |
| --- | --- | --- | --- |
| 林间营地 | 友好的起点与方向参照 | 温暖木屋、林径、层叠针叶树，近景保持可通行 | 木屋、植物、林径、程序化地形与萤火航线营地段已实现；待用户视觉验收 |
| 萤光湿地 | 提供较冷柔的氛围变化 | 水面、低雾与克制的植物微光，突出路径辨识 | P3 原型已实现：浅/深水塘、涉水、冷色雾、湿地声、航线湿地段、光桥与隐藏空地；待试玩 |
| 古树高地 | 用远景与尺度激发探索 | 古树剪影、林冠光束、由近及远的空间层次 | 计划 |

营地与湿地经北侧走廊相连（见 `world/regions.ts`），湿地北端经光桥通往隐藏空地；古树高地的位置、面积、高差与性能预算仍未确定。总概念图采用压缩透视表达气氛，并非地图、关卡承诺或实时画面指标。

## 4. 玩法与交互方案

- **基础操作**：沿用已完成的 WASD 行走、Shift 奔跑、鼠标环视和暂停；移动平滑、树干碰撞、镜头遮挡与焦点丢失暂停已有实现。
- **环境反应**：优先以单个发光植物验证靠近或停留能否被自然发现，反馈强度、距离、复位方式和无障碍提示待确定。
- **萤火航线**：导入方案提出利用灯笼、荧光花或风向引导萤火、点亮设施并开启道路；这是待验证的设计提案，是否必经、具体输入和解锁规则尚未确定。
- **界面与声音**：保留简洁 HUD 和暂停入口；合成环境音、植物空间音符与音量设置已接入（待听感验收），正式音频素材与提示策略为后续工作。

## 5. 美术与资产方案

采用已确认的 Master Art Style Prompt v1：风格化魔法森林，清晰有机剪影、木材与苔藓、克制的暖金与暮蓝、自然的空气纵深。视觉参考包括 [总概念图与说明](concept/README.md) 和导入的[世界与玩法概念板](../concept-art/01_世界设计与玩法总览.png)、[区域与开发概念板](../concept-art/02_区域视觉与开发总览.png)，用于讨论整体氛围；图中角色、道具和建筑细节不可覆盖现有角色参考或资产验收标准。

正式可见 3D 资产遵循 [Meshy 流程](MESHY_PIPELINE.md) 和 [资产清单](ASSET_MANIFEST.md)：参考、生成、验收、优化、集成与许可记录逐项进行；代码可承担地形、碰撞代理与程序化粒子。正式生成服务需要事先明确授权。图中展示的景物不意味着新增资产已排期。

## 6. 技术与交付方案

继续使用 React、TypeScript、Vite、R3F、Three.js 和 pnpm，保持相对路径的静态部署能力。场景、输入、角色、镜头、UI 分工沿用 [工程架构](ARCHITECTURE.md)；高频状态留在帧循环与共享对象内，避免逐帧 React 状态更新。树木采用实例化和 LOD，碰撞与遮挡使用代码代理；未来按真实资源测量加载、绘制与内存，再决定区域加载和压缩方案。

## 8. 待确认事项

- 首批角色、植物和木屋的游戏内视觉验收，以及参考图、模型和动画的权利证明。
- 角色最终尺寸、镜头比例与动画品质；植物反馈及木屋碰撞尺寸。
- 各区域的空间关系、可达范围与可交付规模；玩家引导与存档是否必要。
- 目标设备的帧时间、加载与资源预算，以及最终评审和提交要求。

## 9. 方案来源与排期

[导入的总体方案与开发大纲](../Lumenwood_总体方案与开发大纲_v1.md) 保留为来源文档，包含 15–25 分钟节奏、声音设想、比赛交付清单和 2026-11-09 拟定的日期。其 P0–P5 与现行 [路线图](ROADMAP.md) 的阶段编号含义不同，日期仅为历史目标，不作为实际进度或提交截止日期。英文副标题、类别、比赛规则和交付要求均需核实；未获得确认前不作承诺。

建议后续先验证“发现植物 → 靠近产生光和声音反馈 → 追随线索 → 看到环境变化”的小体验，再决定是否扩大为完整航线与三区域。此建议不改变当前资产验收阶段。
