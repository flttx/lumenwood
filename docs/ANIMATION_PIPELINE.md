# 角色动画流程

## 已实现（2026-11-10，CHR-001）
- **骨架**：Meshy Rigging API 对多图生成的角色自动绑骨，身高 1.6 m，24 根人形骨骼（Hips 为根）。未用 Mixamo，动画来源只有 Meshy 付费套餐。
- **动作**：walking（1.07 s）与 running（0.67 s）随绑骨任务附带；idle 取自 Meshy 动画库动作 0「Idle」（4.03 s）。三段都是原地动作，髋部水平位移为 0，移动由游戏代码驱动。
- **整理**：`scripts/blender/assemble_character.py` 把三个动作文件的 action 改名为 idle / walk / run，挂到同一骨架的 NLA 轨道后导出单个 GLB；删掉绑骨自带的单帧绑定动作；减面放在骨骼修改器之前，避免把姿势烘焙进网格。
- **游戏端**：`player/Character.tsx` 用 drei `useAnimations` 播放，`player/gait.ts` 按速度选动作（< 0.3 m/s 待机，> 5.2 m/s 奔跑，±0.3 m/s 滞回），交叉淡化 0.25 s；走、跑的播放速率随实际速度缩放（走 0.6–1.4 倍、跑 0.8–1.3 倍）。

## 计划
检查脚滑（播放速率与步幅只按比例粗调）、加减速过渡与资源释放；需要时补转身、起步、停步动作。每次生成及动画来源登记在资产清单中。
